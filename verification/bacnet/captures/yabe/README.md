# YABE Capture Lane

This directory stores normalized corpus entries derived from manual YABE
sessions.

Rules:

- no GUI automation scripts live here
- entries must be cataloged in `../catalog.toml`
- each capture must include a `manifest.toml`, `replay.json`, and `runbook.md`
- raw screenshots or ad hoc notes can exist later, but the normalized replay
  artifacts are the long-term source of truth
